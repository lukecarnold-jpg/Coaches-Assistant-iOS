# Coaches Assistant iOS

A local-first iPhone and iPad app for youth and amateur coaches: rosters, live game clock and scoring, fair playing-time rotations, discipline tracking, event history, and AI-generated practice drills across 15 timed team sports — plus stats-only scorecards for Cricket.

Full documentation (features, supported sports and rules, architecture, building and testing) lives in [`Basketball Rotation/README.md`](Basketball%20Rotation/README.md).
